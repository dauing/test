An example repository for demonstrating **DSH superagent**.

## Purpose

This repository is a demo repository that shows how an AI agent takes part in a real development workflow: it receives tasks from a GitHub Issue or a Feishu message, creates a branch, commits changes and opens a Pull Request, and then a human reviews and merges it.

The repository itself contains no production code. All content is demo material, used to verify that the complete "request → agent execution → human review → merge" chain runs smoothly.

## What it demonstrates

- Raising a request through a GitHub Issue;
- Raising a request through a Feishu message;
- Having the agent make documentation changes in the repository and open a PR;
- Merging into the main branch after human review.

## Current state

The repository currently contains only this README, which serves as the vehicle for the demo workflow. Future demo tasks will continue to be recorded here as Issues and PRs.
