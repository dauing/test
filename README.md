一个用于演示 **DSH superagent** 的示例仓库。

## 仓库意义

本仓库是一个 demo（演示）仓库，用于展示 AI 代理如何参与真实的开发协作流程：从 GitHub Issue 或飞书消息中接收任务，创建分支、提交变更、发起 Pull Request，再由人工评审并合并。

仓库本身不包含生产代码，所有内容都只是演示素材，用来验证「任务提出 → 代理执行 → 人工评审 → 合并」这一完整链路是否顺畅。

## 演示内容

- 通过 GitHub Issue 提出需求；
- 通过飞书消息提出需求；
- 由代理在仓库中完成文档修改，并提交 PR；
- 人工评审后合并到主分支。

## 当前状态

仓库目前只有这份 README，作为演示流程的载体。后续的演示任务会继续以 Issue、PR 的形式记录在这里。
